## P06｜Python 后端｜基础

**题干：**接口什么时候可能返回 HTTP 400、404、409、422 或 500？请各举一个例子。

**评价依据：**400 表示错误请求；404 表示资源不存在；409 表示状态或并发冲突；422 可表示请求内容的语法和内容类型可理解，但内容无法按接口语义处理；参数或业务字段校验失败是常见例子；500 表示服务器遇到意外情况，无法完成请求；未处理异常是常见原因之一。

**审核关注：**按接口契约接受合理的 400、409、422 使用；不要机械要求业务校验均返回 422。
