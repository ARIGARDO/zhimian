# 模拟面试题库草案（待审核，不入库）

以下仅供产品与技术负责人审核；未审核前不得启用或作为正式题库导入。题目、难度和参考要点均非唯一标准答案。

| 方向 | 主问题 | 知识点 | 难度 | 考查目标 | 参考要点 |
| --- | --- | --- | --- | --- | --- |
| Python 后端 | 异步函数中调用阻塞数据库驱动会发生什么？如何处理？ | asyncio、阻塞 I/O | 入门 | 理解事件循环阻塞及选型 | 协程切换只发生在可让出控制权处；使用异步驱动或受控线程池；验证超时和连接池 |
| Python 后端 | 如何设计接口的幂等提交，防止客户端重试产生重复订单？ | 幂等键、事务 | 进阶 | 识别并发与重试边界 | 唯一约束、请求摘要、事务内状态转换；外部调用不能保证恰好一次 |
| Python 后端 | 数据库索引为什么可能没有改善查询性能？ | 索引、执行计划 | 进阶 | 利用证据分析查询 | 选择性、联合索引顺序、统计信息、回表和执行计划；结合实际数据库验证 |
| Python 后端 | 缓存过期时如何降低热点请求同时穿透数据库的风险？ | 缓存击穿、锁 | 进阶 | 设计容错与并发控制 | 互斥或请求合并、过期策略、超时降级；说明锁失效与一致性权衡 |
| AI 应用 | 构建 RAG 时如何定位回答没有依据的问题？ | 召回、证据、评测 | 入门 | 分辨检索与生成问题 | 检查数据、切分、召回/重排、上下文引用；用测试集分别评估 |
| AI 应用 | 关键词检索和向量检索各有什么优势？如何融合？ | 混合检索、RRF | 进阶 | 理解召回互补和融合权衡 | 关键词精确匹配、语义召回；RRF 不要求分数可比；评估延迟与召回 |
| AI 应用 | Agent 调用外部工具时如何限制越权和恶意输入？ | 工具权限、注入 | 进阶 | 识别信任边界 | 最小权限、参数校验、敏感操作确认、隔离和审计；模型输出不可信 |
| AI 应用 | 如何评估模型应用改动是否改善了真实效果？ | 离线评测、质量和成本 | 进阶 | 构造可复现评估 | 代表性数据集、基线、正确性与安全指标、成本延迟；人工抽检与回归 |
