# M3-05 模拟面试前端实施报告

## 目标与实际完成

按 V2.5 和 V0.4 原型接入既有面试服务，实现配置、进行中、历史和报告页面；面试状态与完成条件由服务端决定。本轮没有开发 M3-06，没有新增框架或依赖，也没有修改后端 API、数据库结构或迁移。

- `frontend/src/pages/InterviewPage.tsx`：标准题库和岗位预设、可选 JD、练习/正式模式及题数/时长配置；创建、开始、出题、回答、练习跳题、关闭主问题、主动终止；按状态展示历史、完整报告、部分复盘与无内容提示。追问和练习反馈由用户按需触发，正式模式进行中不展示反馈入口、评分或报告。
- `frontend/src/features/interview/api.ts`、`useAction.ts`：封装现有 API、类型、幂等写入与操作轮询。TanStack Query 读取服务端状态，未把面试数据库复制到 Zustand；使用会话级 `sessionStorage` 保存未确认请求的原键与原体。模型请求前端 15 秒超时后仍保留原请求，允许恢复并查询操作；`running` 轮询，`failed` 根据 `retryable` 决定能否重试，处理 `complete` 和 `no_content`。不新增 SSE。写操作通过同步锁防止同一页面的重复点击。
- `frontend/src/app/router.tsx`、`frontend/src/styles/globals.css`：新增页面路由、按需加载及响应式样式；`AppLayout.tsx`、`HomePage.tsx` 更新入口文案。`frontend/tests/interview-api.test.cjs` 增加原键原体恢复与到期错误检查。

V0.4 的工作台导航、配置分组、模式选择、问题卡片、进度与报告结构在现有组件和配色上实现；没有照搬原型中的演示题、示例回答、模拟中断或虚构报告。页面根据真实 API 返回的预设展示名称与题量。时长题库耗尽时提示等待到期或主动结束，不改变状态机。

## 产品边界

- 正式 PostgreSQL 的 `interview_presets`、`interview_question_bank` 均为 0：无审核通过题库，正式环境目前不能创建面试。测试专用题库只存入独立临时数据库。
- 正式模式面试进行中不显示评价、评分、跳题或报告；终态不允许继续作答。未完成报告仅渲染文字，页面即使收到综合分字段也不会展示。无有效回答时明确提示无内容，不创建学习任务。
- 完整报告中的 0～100 分标注为“候选量表，尚待产品确认”，不代表评分质量经过验证。时长模式题库耗尽方案和正式题库审核仍待产品决定。

## 实际测试与结果

- `cd frontend && node --test tests/interview-api.test.cjs`：2 项通过，核对同一逻辑请求的键和请求体可重放，以及到期 409 的提示。
- `cd frontend && npm run typecheck && npm run build`：通过。首次误在仓库根目录执行 npm 命令因没有 `package.json` 失败；切换到 `frontend` 后重跑通过。
- `cd backend && PYTHONPYCACHEPREFIX=/tmp/zhimian-pycache /tmp/zhimian-m2-venv/bin/pytest -q`：74 项通过，涵盖 M1/M2/M3 服务端回归；现有 pytest-asyncio 和 Starlette 存在弃用提示。
- 使用标准 Compose 的 PostgreSQL 和当前后端镜像，创建仅用于测试的独立库与仅本机开放的临时后端，前端使用 Vite 开发服务器；检查实际 `/openapi.json` 的面试路径及操作查询接口。Safari 桌面实际验证：创建练习面试、开始、读取题目、提交答案、模型请求中刷新后使用原请求恢复、真实模型反馈和追问、提前结束、真实模型部分复盘；正式模式完成三题并取得真实模型完整报告，进行中未出现跳题和逐题反馈。测试问题和回答均为隔离数据。
- 在隔离库调整测试场次数据库时间后，Safari 直接访问显示无活动中断且不可续答；另一无回答场次显示“暂无可复盘内容”。停用隔离预设时配置页显示无题库并禁止创建。Safari 以桌面窗口和放大页面触发窄 CSS 视口断点检查布局；这不等同于真实移动设备或移动版 Safari 验收。
- 同一隔离环境的 M1 专题目录、文章和完成进度，以及 M2 专题聊天真实模型流式回复通过浏览器回归。

## 风险与待独立验收

1. **正式题库仍未审核入库，是正式使用的阻塞项。** 测试库不作为正式内容。
2. 真实移动设备、移动版 Safari、弱网/反向代理实际 504、浏览器自动化重复点击及模型失败后达到重试上限的完整页面流程尚未验证；幂等和部分失败边界有服务端或前端接口测试，不能代替这些浏览器验收。页面当前不展示实时倒计时，仅展示服务端截止时间，并定期刷新服务端状态。
3. `sessionStorage` 在当前标签页保留待确认请求体，其中可能包括 JD 或回答；关闭标签页后可能无法恢复未知结果，且同源脚本可读取。模型操作无按场次列出接口，丢失标签页本地记录后无法通过现有接口主动发现未知操作 ID。历史每类当前最多读取 100 条，未提供翻页。
4. 部分复盘的自然语言过滤存在漏判/误判风险；候选评分量表与 AI 评价质量尚待产品和专家确认。服务端无用户认证，不宜直接暴露给不可信用户。

本轮页面及已列出的联调已完成；**建议进入独立技术评审，但不建议在正式题库就绪和上述浏览器关键场景补验前宣布 M3-05 最终验收通过**。未开始 M3-06。
