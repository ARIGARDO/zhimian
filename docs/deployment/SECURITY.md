# M1 安全边界

**本代码尚未经过生产安全审计，不是一个可匿名开放到公网的多用户服务。**

- Compose 前端默认只绑定 `127.0.0.1:8080`，PostgreSQL 没有对宿主机暴露端口。
- 无平台注册系统；同一数据库中的学习进度由该单实例共享。访问该实例的人理论上可修改进度。
- 公开到互联网前，必须增加 HTTPS、访问保护、反向代理安全设置、速率限制及资源访问控制。
- 未来的 Chat/Embedding API Key 必须存在服务端，不得放进 `VITE_` 变量、前端代码、数据库响应或日志。
- 以后实现自定义 Base URL 时，应防范 SSRF；文档上传必须做文件类型、大小、解压体积、解析时间与权限检查。
- 当前 `POSTGRES_PASSWORD` 默认值仅供本机测试。远程部署应使用强随机密码，配置安全密钥注入。
- Docker 数据卷只负责持久化，不代表自动备份；升级前应执行 PostgreSQL 备份，验证恢复流程。
